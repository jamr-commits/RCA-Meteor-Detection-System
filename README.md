# RCA-Meteor-Detection-System
This repository is for the 2026-2027 ECE capstone team at Portland State University to document their work on the Rose City Astronomer's Meteor Detection System. This is an open source project designed to assist with RCA and PSU's Radio astronomy club for detecting and analyzing meteors using radio telescopes.
